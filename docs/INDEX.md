# Gameplay Tag Refactor Pro — Documentation

**Current documentation target:** Gameplay Tag Refactor Pro v1.0.0 for Unreal Engine 5.8.

Gameplay Tag Refactor Pro (GTRP) provides a controlled editor workflow for scanning Gameplay Tag usage, previewing rename impact, refactoring supported references, verifying the saved result, auditing project-owned tag structure, and exporting reports.

## Recommended first-use path

1. [Install and enable GTRP](01_Installation.md).
2. Follow the [Quick Start](02_Quick_Start.md).
3. Read the [Core Workflow](03_Core_Workflow.md) before the first rename.
4. Use the [Reference](04_Reference.md) when you need exact feature or audit behavior.
5. Review [Troubleshooting, FAQ & Limitations](08_Troubleshooting_And_FAQ.md) before assuming every runtime/dynamic tag usage can be discovered automatically.
